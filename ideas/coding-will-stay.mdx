# Coding will stay

In a talk entitled "", Rainer Stropek presents some interesting ideas around AI and learning/teaching to code. 

> Coding will stay, not because it's the fastest way to build software, but because it's a powerful way to train a certain kind of thinking.

> Coding teaches precision, logic, precision; it teaches you what it feels [like] when the computer does exactly what you told it to do.

> The answer is not to fight the tool. The answer is to find the layer above it.

> The new programming language is clarity.
